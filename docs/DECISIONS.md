# Architecture Decision Records

## ADR-001: Astroを採用
採用。技術思想と作品・記事の静的配信を優先し、Reactをグラフ領域に限定する。Next.jsは現時点の要件には過剰。

## ADR-002: グラフはSVG + Reactで開始
採用。固定ノード数の視覚表現にforce-directed/React Flowは不要。ノード増加や編集の要件が出たら再評価する。

## ADR-003: CMS接続をMVPから除外
採用。将来は既存Headless CMSを暫定利用し、その後自作CMSに移行。データ取得層に依存を閉じる。

## ADR-004: グラフを唯一のナビゲーションにしない
採用。アクセシビリティ・発見性・モバイル体験のため、通常のリンクを併設する。

## ADR-005: 未決定の作品はダミー表示
採用。実績を捏造しない。公開前に実データへ置換または非表示とする。
