# MVP 要件定義

## 目的
「アイデアは、日常に転がっている。」を軸に、日常の不便・疑問・好奇心と、そこから生まれる制作物・考察・実験の関係を視覚的に表現する。

## 読者
技術者に限定しない。初見でコンセプトを理解でき、興味があれば深掘りできる。

## スコープ
| ID | 要件 | 受入条件 |
|---|---|---|
| FR-01 | Home | コンセプト、グラフ、作品、Aboutを表示 |
| FR-02 | Graph | キーボードとポインタでノードを選択できる |
| FR-03 | Graph relations | 選択ノードの接続先とエッジが強調される |
| FR-04 | Graph details | 選択ノードの説明とリンクが見える |
| FR-05 | Works | `/works` に代表作品の一覧を表示 |
| FR-06 | Writing | 初期は外部記事への導線。未登録なら捏造しない |
| FR-07 | Responsive | モバイルでも通常ナビとグラフを利用可能 |
| FR-08 | Reduced motion | OSのモーション軽減設定を尊重 |
| FR-09 | Static | 認証、DB、API、CMSを必要としない |

## Non-goals
自作CMS、既存CMS接続、ブログ本文配信、検索、ノードの自由編集、力学シミュレーション、無限ズーム、ログイン、アクセス解析。

## 品質
- JavaScript無効時にも通常リンクと文章で主要情報を読める
- キーボードフォーカスを表示し、ノードに意味のあるラベルを付ける
- Web Vitals / Lighthouseを計測し、90点以上を目標とする（保証値ではない）
- 画像や動的表現はアクセシビリティと可読性を阻害しない
- 公開URLを変更せず将来CMSに移行可能なID/slugを使う

## Definition of Done
[ ] 実データでHomeとWorksを表示する
[ ] ノード・エッジが選択に応じて更新される
[ ] キーボードだけでリンクまで到達できる
[ ] 320px相当の画面で横はみ出ししない
[ ] `pnpm check` と `pnpm build` を通す
[ ] 権利や非公開情報を含まないことを確認する
[ ] 公開環境で実機確認する
